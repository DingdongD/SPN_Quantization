# NLSPN Frame-Difference Five-Frame Visualization Design

## Goal

Re-run frames 0001 through 0005 with the frozen NLSPN checkpoint and produce
directly comparable depth and absolute-error visualizations for full NLSPN,
zero-flow residual prediction, RGB-difference cache, and global-translation
cache. Keep the formal 256-frame benchmark directory and its six-artifact
contract unchanged.

## Considered approaches

### A. Dedicated reproducible visualization worker (selected)

Add a small legacy-environment worker and current-environment launcher that
reuse the validated preprocessing, checkpoint loader, causal engine, and
selected formal configurations. Save a compact prediction archive, metrics,
metadata, and figures in a separate directory. This adds a testable path and
makes the figures reproducible without changing benchmark semantics.

### B. One-off interactive plotting command

Run inference from an ad hoc Python snippet and save only PNG files. This is
faster to write, but does not preserve exact inputs/configurations or provide a
repeatable validation contract.

### C. Extend the formal 256-frame benchmark

Make the existing worker persist predictions and plots. This would violate the
approved no-tensor-cache and exact-six-file output contract, and would require
an unnecessary full rerun.

Approach A is selected because it separates scientific visualization from the
timing experiment while retaining full provenance.

## Inputs and inference

- Scene: `BeachApartmentInterior_My_ir`.
- Frames: 0001, 0002, 0003, 0004, and 0005, treated as one causal clip.
- Geometry: the validated 304 x 228 preprocessing path.
- Sparse depth: exactly 500 points per frame with seed 2026, generated by the
  existing shared sparse-depth builder.
- Checkpoint: the existing frozen ResNet-34 NLSPN iteration-18 TGASS model with
  `preserve_input=false`.
- Schedule: I, P, I, P, I. Each method resets before the clip.
- Full reference: full NLSPN inference on all five frames.
- Zero-flow: the parameter-free zero-flow configuration.
- RGB-difference and global-translation: load the two rows marked selected in
  the formal `threshold_sweep.csv`. Require exactly one selected row per
  variant and record the formal artifact digest.
- Inference is performed once per path. Timing is informational only and is not
  merged into the formal benchmark.

## Output directory and artifacts

Write to:

`/workspace/VoxelNet/nlspn_frame_difference_cache/BeachApartmentInterior_My_ir/frames_0001_0005_visualization`

The exact artifacts are:

4. `frame_metrics.csv`
5. `run_metadata.json`
6. `worker.log`

The NPZ archive contains frame IDs, RGB, sparse depth, ground truth, validity,

the formal pilot directory remains untouched.

## Figure design

### Depth comparison

- Five rows, one per frame.
- Five columns in this order: Ground truth, Full NLSPN, Zero-flow, RGB-diff,
  Global-diff.
- Viridis colormap with an identical 0 to 10 m range for every panel.
- Invalid ground-truth pixels are white.
- One external shared colorbar labeled `Depth (m)`.
- Row labels use `Frame 0001` through `Frame 0005`.

### Absolute-error comparison

- Five rows, one per frame.
- Four columns: Full NLSPN, Zero-flow, RGB-diff, Global-diff.
- Error is absolute prediction minus ground truth on valid pixels only.
- All panels use one shared scale from 0 to the common valid-pixel 99th
  percentile across all four methods and five frames. Record the numerical
  upper limit in metadata.
- Invalid pixels are white and one external shared colorbar is labeled
  `Absolute error (m)`.

Figures use the noninteractive Agg backend, fixed layout, fixed DPI, and no
per-panel autoscaling.

## Metrics and provenance

`frame_metrics.csv` contains 20 rows: four prediction methods times five
frames. Each row records RMSE, MAE, valid pixels, sparse count, frame kind,
and latency. `run_metadata.json` records checkpoint and args digests, formal
sweep digest, selected configurations, frame IDs, preprocessing geometry,
seed, device, versions, error scale, artifact list, and completion state.

## Error handling and validation

- Reject missing or ambiguous selected configurations.
- Reject a checkpoint or model configuration different from the validated
  NLSPN setup.
- Reject prediction geometry mismatches and non-finite valid predictions.
- Write NPZ, CSV, JSON, and PNG artifacts atomically where practical; mark
  metadata complete only after all six files are nonempty.
- Validate archive shapes, exact frame/method counts, common figure scale,
  digests, and output scope in the launcher.
- Unit tests cover selected-configuration parsing, I/P scheduling, metric
  counts, figure geometry/colorbar placement, command construction, and final
  artifact validation. A real five-frame run is the final integration check.

## Success criteria

- Both comparison figures exist and are readable.
- The depth figure uses exactly 0 to 10 m for all depth panels.
- The error figure uses one documented common scale.
- All four methods have five finite predictions and 20 metric rows.
- Selected RGB/global configurations match the formal pilot.
- The formal `pilot_256` directory remains byte-for-byte unmodified.
